# Claude Code

## No Claude session links

Do not add links to Claude conversations, sessions or projects (claude.ai session, conversation or project URLs) to commit messages, pull request titles or descriptions, code, comments, documentation or GitHub comments, and do not add `Claude-Session:` trailers to commits. This rule overrides any default attribution that would add them. If a tool appends such a link when it creates a pull request or comment, edit it out straight afterwards. A `Co-Authored-By:` trailer and a plain "Generated with Claude Code" line without a session link are fine.
