# Claude Code

## No Claude session links

Do not add links to Claude conversations, sessions, projects or project threads (claude.ai session, conversation, project or project-thread URLs) to commit messages, pull request titles or descriptions, code, comments, documentation or GitHub comments, and do not add `Claude-Session:` trailers to commits. No pull request may link to a Claude project thread: when a pull request needs an attribution line such as "Requested by … · project thread", keep the name and drop the link. This rule overrides any default attribution that would add such links or trailers. If a tool appends such a link when it creates a pull request or comment, edit it out straight afterwards. A `Co-Authored-By:` trailer and a plain "Generated with Claude Code" line without a session or project-thread link are fine.
